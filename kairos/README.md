## ⚡ About Kairos

**Kairos** is a minimalist, high-performance focus timer and timebox engine built with a focus on deep work and distraction-free productivity. Named after the ancient Greek concept of the *opportune, right moment*, Kairos provides structured focus sessions with procedural sound synthesis and zero tracking.

### Key Features

* **⏳ SVG Circular Ring Gauge:** Hardware-accelerated SVG countdown ring with dynamic color themes per mode (Focus, Short Break, Long Break).
* **🔔 Synthesized Completion Bells:** Real-time synthesized harmonic chimes (528Hz Digital Chime, 432Hz Zen Bowl, Soft Marimba) generated algorithmically via native Web Audio API (*zero audio file downloads needed*).
* **🛡️ Zero Dependencies & Privacy First:** Built with pure Vanilla JS and CSS3. All session history and focus statistics stay strictly in local browser `localStorage`.
* **⌨️ Keyboard Shortcuts:** Quick control using `Space` (Play/Pause), `R` (Reset), and `S` (Skip).

---

## 🛠️ Tech Stack

* **Core:** HTML5, CSS3 Variables, Vanilla ES6+ JavaScript.
* **Audio Engine:** Native Web Audio API (`AudioContext`, `OscillatorNode`, `GainNode`).
* **Storage:** `localStorage` (Privacy-first stats tracking).
