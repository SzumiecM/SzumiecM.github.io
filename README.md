## ⚡ Overview

**[SzumiecM.github.io](https://szumiecm.github.io/)** is a portfolio hub hosting fast, private, and distraction-free web applications. Built strictly with native web standards—pure HTML5, CSS3 keyframe animations, glassmorphism, and vanilla JavaScript—with **zero external runtime dependencies or imported frameworks**.

## 🎨 Core Design & Engineering Principles

* **⚡ Zero External Dependencies:** No node_modules, no heavy JS frameworks, no external Google Fonts or font icons. Everything is self-contained.
* **🛡️ Privacy & Security First:** Minimal data footprints, local-only persistent storage (`localStorage`), no third-party telemetry, and enforced strict security headers.
* **✨ Modern Pure CSS Aesthetics:** Dark theme glassmorphism (`backdrop-filter`), CSS variables, responsive grid systems, and smooth keyframe animations.
* **🚀 Instant Load Times:** Ultra lightweight payload size (<10 KB), optimized system typography stack, and instant rendering.
